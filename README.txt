GITHUB PAGES UPLOAD
1. Download and unzip this package.
2. Open the extracted OGC_One_Glove_Crew folder.
3. Upload index.html and the entire assets folder to the ROOT of your GitHub repository.
4. Keep the assets folder beside index.html. Do not upload index.html by itself.
5. In GitHub, open Settings → Pages and select Deploy from a branch, then choose the main branch and /(root).
6. Save and wait for GitHub Pages to publish the site.

No backend, customer account system, payment gateway or order database is included in this preview.
